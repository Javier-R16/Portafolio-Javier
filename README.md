# Portafolio de proyectos

Página de presentación con mis sistemas, apps, dashboards y agentes de IA.

Es un sitio estático: `index.html` y la carpeta `img/`. No necesita instalar nada.

## Publicar en Vercel
1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel: **Add New → Project**, elige el repositorio y pulsa **Deploy**. No hace falta configurar nada.

## Verlo en tu computadora
Abre `index.html` en el navegador.

## Antes de publicar
Revisa tus datos de contacto en `index.html`.

Las pantallas son de sistemas reales mostradas con datos de ejemplo: los nombres y montos son ficticios.
